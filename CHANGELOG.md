# 更新日志 / Changelog

## 未发布 / Unreleased

### 简体中文

- 创造栏提供空壳和未绑定的紧凑流体源。放下成品，创造玩家可以用装有流体的容器右键选液、换液，用空桶清空，手里的容器照常保留。生存玩家无法改绑。
- 新增紧凑流体源。用一个流体储罐和一个软管滑轮合成空的紧凑流体源，再用注液器逐桶加工。半成品可在置物台和传送带之间转移，保留流体和进度。
- 默认支持所有可放置源方块的流体，包括蜂蜜和巧克力。水固定 3 桶，其他流体默认 10,000 桶，整合包可调。Create 药水等虚拟流体无法注入。软管滑轮门槛为 `-1` 时暂停注液与供液。
- 成品可从六面接管抽液。铜玻璃机壳上的刻度窗和窄窗检修盖可以看到内部流体。

### English

- The creative tab contains an empty workpiece and an unbound finished source. Creative players can right-click a placed source with a filled container to set or replace its fluid, or use an empty bucket to clear it. Both actions keep the container. Survival players cannot change the binding.
- Added the Compact Fluid Source. Craft an Empty Compact Fluid Source from one Fluid Tank and one Hose Pulley, then fill it one bucket at a time with a Spout. Moving the workpiece between a Depot and a Mechanical Belt preserves its fluid and progress.
- All fluids with placeable source blocks qualify by default, including honey and chocolate. Water takes 3 buckets and other fluids default to 10,000. Modpacks can change the non-water cost. Virtual fluids such as Create potions are rejected. A Hose Pulley threshold of `-1` pauses filling and output.
- A pump can draw fluid from any of the six faces. The gauge windows and the narrow inspection window in the copper lid show the fluid inside.
