# 机械动力：便携供应

[English](readme.en.md)

一个面向 Minecraft 1.21.1 NeoForge 的机械动力附属模组。玩家可以把一座大宗供应设施做成一格方块，建造时仍需投入对应的部件和资源。

**便携流体源**由一个流体储罐和一个软管滑轮合成毛坯，再用注液器向同一件毛坯逐桶注入流体。首次注液锁定流体种类和目标次数。半成品可在置物台与传送带之间转移，铜玻璃后的液面随进度升高。成品可以从六个面接管，用动力泵持续抽取绑定的流体。

流体资格跟随机械动力软管滑轮的无限源设置。默认可用水和熔岩，各需 10,000 桶。整合包可以在 `portable_supply-server.toml` 中用 `requiredFills` 指定新毛坯的注液次数，设为 `0` 时跟随软管滑轮门槛。

铜玻璃机壳采用《机械动力：流光溢彩》的材质。[材质许可](src/main/resources/META-INF/licenses/LICENSE-CreatePrism.txt)
